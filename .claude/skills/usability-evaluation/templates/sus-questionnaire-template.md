## 2. Thang đo SUS 10 câu (5-point Likert Scale)
*(Thang điểm: 1 = Rất không đồng ý | 2 = Không đồng ý | 3 = Trung lập | 4 = Đồng ý | 5 = Rất đồng ý)*

| STT | Câu hỏi khảo sát (Standard SUS Item) | 1 (Rất không đồng ý) | 2 (Không đồng ý) | 3 (Trung lập) | 4 (Đồng ý) | 5 (Rất đồng ý) | Điểm quy đổi (Item Score) |
|:---:|:---|:---:|:---:|:---:|:---:|:---:|:---:|
| 1 | Tôi nghĩ rằng tôi sẽ thích sử dụng hệ thống này thường xuyên. *(I think that I would like to use this system frequently.)* | | | | | | *(Q1 - 1)* |
| 2 | Tôi thấy hệ thống này phức tạp một cách không cần thiết. *(I found the system unnecessarily complex.)* | | | | | | *(5 - Q2)* |
| 3 | Tôi thấy hệ thống này dễ sử dụng. *(I thought the system was easy to use.)* | | | | | | *(Q3 - 1)* |
| 4 | Tôi nghĩ rằng tôi sẽ cần sự hỗ trợ của một chuyên gia kỹ thuật để có thể sử dụng hệ thống này. *(I think that I would need the support of a technical person to be able to use this system.)* | | | | | | *(5 - Q4)* |
| 5 | Tôi thấy các chức năng khác nhau trong hệ thống này được tích hợp rất tốt. *(I found the various functions in this system were well integrated.)* | | | | | | *(Q5 - 1)* |
| 6 | Tôi thấy có quá nhiều sự thiếu nhất quán trong hệ thống này. *(I thought there was too much inconsistency in this system.)* | | | | | | *(5 - Q6)* |
| 7 | Tôi tưởng tượng rằng hầu hết mọi người sẽ học cách sử dụng hệ thống này rất nhanh chóng. *(I would imagine that most people would learn to use this system very quickly.)* | | | | | | *(Q7 - 1)* |
| 8 | Tôi thấy hệ thống này rất cồng kềnh/bất tiện khi sử dụng. *(I found the system very cumbersome to use.)* | | | | | | *(5 - Q8)* |
| 9 | Tôi cảm thấy rất tự tin khi sử dụng hệ thống này. *(I felt very confident using the system.)* | | | | | | *(Q9 - 1)* |
| 10 | Tôi cần phải học rất nhiều điều trước khi có thể bắt đầu sử dụng hệ thống này. *(I needed to learn a lot of things before I could get going with this system.)* | | | | | | *(5 - Q10)* |

**Công thức tính điểm SUS của người tham gia**:
$$\text{SUS Score} = \left[ \sum_{i \in \{1,3,5,7,9\}} (Q_i - 1) + \sum_{j \in \{2,4,6,8,10\}} (5 - Q_j) \right] \times 2.5$$
